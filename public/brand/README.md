# Брендовые ассеты БЕЗ ВОДЫ

Для сайта закреплены два варианта: полная надпись "БЕЗ ВОДЫ" для крупного брендинга и превью ссылок, компактный "БВ" для вкладок, закладок и иконок телефона. Компактный вариант отдельно запрошен пользователем после проверки читаемости полного логотипа в маленьком favicon. Не заменять эти варианты знаком Lovable, котом, эмодзи или иным неутвержденным изображением.

## Текущий компактный набор, версия 2

- Версия набора значков: `20261103-bv-v2`
- Требование пользователя: только "БВ" с зачеркиванием, белые буквы на черном фоне
- Канонический PNG-мастер компактного знака задается в `branding.json` полем `iconSource`, его SHA-256 - полем `iconSourceSha256`
- Favicon, Apple Touch и web manifest используют этот компактный набор
- `sourceLogo` и `shareImage` продолжают ссылаться на полную надпись из версии 1

Компактный PNG создан генератором изображений по новой просьбе пользователя. Это отдельный утвержденный вариант знака, а не точная обрезка букв из первоначальной полной надписи. Для него не заявляется побайтное или пиксельное совпадение с буквами версии 1. Полученный PNG закреплен как мастер, последующие размеры готовятся техническим масштабированием. Не генерировать знак заново при каждой сборке.

Корневые `public/favicon.ico`, `public/favicon.svg`, `public/apple-touch-icon.png` и `public/site.webmanifest` должны быть побайтными копиями файлов текущей версии значков. Проверка брендинга сверяет SHA-256 компактного мастера, кадры ICO 16/32/48, PNG-размеры, manifest и стабильные копии. Старый набор версии 1 сохраняется для истории и ранее опубликованных ссылок.

## История подготовки полной надписи, версия 1

Владелец разрешил убрать подпись "withoutwater" из производных ассетов. Для этого выполнена прямоугольная обрезка исходника: левый край x=181, верхний край y=410, ширина 1097 px, высота 153 px. Правая и нижняя исключающие границы - x=1278 и y=563. Результат: `20261103-97c91f04/logo-wordmark.png`.

Проверка RGB-пикселей обрезки с соответствующей областью исходника показала 0 отличий. Сохранены все буквы, исходная черная полоса и небольшой запас темных пикселей вокруг надписи. Буквы не перерисовывались, шрифт не заменялся, новый знак не создавался.

Остальные изображения получены из этой обрезки штатным `sips`: масштабирование по ширине с сохранением пропорций и округлением высоты до целых пикселей, затем центрирование на черном холсте. Не растягивать надпись по одной оси для заполнения квадратной иконки. В размере 16x16 полная широкая надпись занимает около двух пикселей по высоте, поэтому ее читаемость ограничена исходными пропорциями.

Единый конфиг находится в корне репозитория: `branding.json`. Он хранит root-relative пути версии, название "БЕЗ ВОДЫ", origin `https://nowater.tech`, черный цвет темы и размеры изображения для ссылок. Дубликат конфига в `public` не создавать.

При выпуске версии 1 корневые fallback были копиями ее файлов. После перехода на компактную версию 2 стабильные адреса обновлены на компактные значки. Файлы версии 1 при этом не удаляются.
